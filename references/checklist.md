# 交付前檢查清單（使用者的偏好，每款都要）

## 內容與授權
- [ ] 改編作品：人物造型、台詞、場景、年代照原作（劇照、劇本），不自創；台詞標出處、經典段落只放關鍵句
- [ ] 真人照片只當參考，臉畫成原創像素臉；暴露的參考圖只拿臉部裁切給 GPT
- [ ] 依設定圖畫角色：衣服、髮型、配件照設定，不要自己加道具；生完並排比對
- [ ] 經典招式「像但不一樣」（動作與指令都不同），除非使用者點名要致敬
- [ ] 每個角色的招式與必殺姿勢各不相同，也真的有不同特點（速度、力量、遠距離、霸體、反擊…）
- [ ] 品牌商品用官方照片（只裁商品、不含價格）；沒授權的商標不畫
- [ ] 字型、音樂、美術都是原創或可商用授權（README 寫清楚）

## 美術
- [ ] 角色是逐格動作圖（不是程式畫的小人）；走路、跑步、跳、出招都有連續動作
- [ ] 背景是整張繪製的像素圖；不要有接縫；招牌字用程式疊
- [ ] 生成圖逐張檢查：多手、多手指、手太長、破圖、殘留洋紅 → 重生
- [ ] 頭像、立繪、選角畫面、結局都用同一套畫風

## 遊戲
- [ ] 開機畫面「點一下開始」（開聲音）→ 開場動畫（5～8 秒，品牌／角色）→ 標題
- [ ] 選角、每關戰鬥、結局都有各自的配樂；每個場景都有音效
- [ ] 打擊感：hitstop、震動、火花、粒子、連擊數
- [ ] 桌墊出招表（網頁下方）＋暫停選單出招表；手機有觸控按鍵、必殺有快捷鍵
- [ ] 判定要合理好打（例如車底、低處要蹲下打得到；飛起來的東西要跳起來打）
- [ ] 不做每日登入、儲值、月卡、等時間、社交
- [ ] 防誤觸放大（連點、兩指、Ctrl＋滾輪）與選取、拖曳、長按選單
- [ ] 標題畫面有版本號，遊戲內看得到更新紀錄，每次改版加一筆

## 交付
- [ ] bot 跑過每個角色×每一關，難度合理；全流程沒有錯誤
- [ ] 手機尺寸（直、橫）版面確認；按鍵不互相蓋住
- [ ] push 前先問使用者（除非他說做好就推）；上線後開線上版確認
- [ ] 回報時說清楚：做了什麼、怎麼玩、哪些沒驗證到（例如沒有實機聽聲音）
