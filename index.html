CLAUDE CODE SKILL ・ ARCADE-GAME-MAKER

街機像素遊戲工坊

用 GPT 畫逐格動作圖與像素背景、程式切格對齊、合成配樂、手機觸控，做出 90 年代街機風格的網頁小遊戲。下面是做出來的作品、可以直接玩的範本，以及整套流程。

玩範本：沙包練習場 GitHub 原始碼

作品用這套流程做的遊戲

點標題可以直接玩，手機、電腦都可以。

紅分子 亮車快打

格鬥 ・ 獎勵關 ・ 品牌合作

快打旋風「打車關」反過來：限時把髒車打到發亮。8 位角色各有專屬必殺，4 關（車庫、夕陽洗車站、雨夜、飛天電動車），開場動畫、官方商品照、桌墊出招表、排行榜。

讓子彈飛：鵝城快打

橫向清版 ・ 改編電影 ・ 多結局

騎馬劫火車序章、鵝城街道清版、鴻門宴過場、夜襲縣衙、碉樓決戰；造型與台詞照原作劇本，每位兄弟有不同特點（遠距離、霸體、反擊）。

沙包練習場（範本）

最小可玩範例 ・ 新專案從這裡複製

30 秒內打爆越多沙包越好。示範走路、跑步、跳、蹲、拳腳、飛彈、迴旋、打擊停頓、粒子、暫停、版本與更新紀錄、桌墊出招表。

流程SKILL.md 的 0～7

交付前一定檢查

  • 改編作品的造型、台詞、年代照原作；真人照片只當參考，臉畫成原創像素臉
  • 經典招式「像但不一樣」，每個角色的招式與特點真的不同
  • 角色是逐格動作圖、背景是整張像素畫；生成圖逐張檢查多手多指
  • 防誤觸放大與選取；標題有版本號、遊戲內看得到更新紀錄
  • 不做每日登入、儲值、等時間；上線前先問
